# Cloud vs Monitoring actions

Brand new installation contains from several non trivial steps, so it is good to specify "what(action) - who - where" relations.


|  Action                               | Who                  | Where      |
| ------------------------------------- | ---------------------| -----------|
| Creating a customer                   | Sales representative | Cloud      |
| Creating a property                   | Sales representative | Cloud      |
| Creating an InstallationDraft                  | Designer (aiming Tech.)           | Documentation now, Monitoring future |
| Creating a sensor(s)                  | Technician           | Monitoring |
| Creating an entrance(s)               | iC Lab               | Monitoring |
| Creating an area(s)                   | iC Lab               | Monitoring |
| Defining entrance groups           | Designer (aiming Tech.)      | Documentation now, Monitoring future      |
| Creating an entrance groups           | iC Lab      | Cloud      |
| Craeting an users                     | Sales representative | Cloud      |
| Assigning the property to the user    | Sales representative | Cloud      |
| Assigning the entr. group to the user | Sales representative | Cloud      |
| Assigning the reports to the user     | Sales representative | Cloud      |
