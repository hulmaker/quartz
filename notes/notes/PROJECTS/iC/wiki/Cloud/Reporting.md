# Reporting

The main communication canal to a customer is reporting. Currently customer can
- visit web application and based on several filters create a report of his desire.
- receive periodical reports via email

Periodicity of report sending
- daily
- weekly
- monthly

Supported formats and form
- PDF (prezentation form)
- Excel/CSV (data form)

PDF reports are generated using HTML templates.

!! Definition of a report is currently possible edit only directly in DB. !!
