With use of the [[Gradient Clipping]] it is possible to outperform nets for image recognition that uses [[Batch Normalization]]. Problem with the batch norm. is, that you usually need large batches of data. However often it is not possible to provide large enough batches e.g. in [[Reinforcement Learning]]. It might be a good idea to avoid the normalization using the NFNets.
