# Ingredience 14 porcí - cca 1kg cibule

| Množství      |                    |
| ------------- | ------------------ |
| 2.8 ks        | chilli paprička    |
| 140 ml        | červené víno       |
| 1.4 lžička    | čerstvý zázvor     |
| 70 ml         | červený vinný ocet |
| 4.2 lžíce     | balzamikový ocet   |
| 1050 g        | červená cibule     |
| 210-280 g     | třtinový cukr      |
| podle potřeby | olej               |
| podle chuti   | sůl                |
| podle chuti   | mletý černý pepř   |
# Postup
Cibuli oloupeme a nakrájíme na silnější kolečka. Oloupaný zázvor nastrouháme a očištěnou chilli papričku drobně nasekáme. 

Na oleji orestujeme za stálého míchání cibuli a papričky do tmavě zlatova. Pak vmícháme strouhaný zázvor, vše podlijeme vínem a ochutíme balzamikovým a vinným octem a cukrem. Směs osolíme, opepříme a zvolna vaříme za občasného míchání tak dlouho, dokud nezhoustne. 

Vlažné chutney přendáme do předem sterilované sklenice a uzavřeme. Cibulové chutney skladujeme v chladu, kde vydrží alespoň měsíc. 

Cibulové chutney podáváme jako přílohu k masům, ale samozřejmě najde uplatnění i při přípravě dalších pokrmů - jako jsou slané omelety se slaninou, toasty se sýrem. Výborně chutná i v nejrůznějších pomazánkách.
