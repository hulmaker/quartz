Very powerfull [[Reinforcement Learning]] algorithm suitable for combinatoric games.

**In late 2017 we** [**introduced AlphaZero**](https://arxiv.org/abs/1712.01815)**, a single system that taught itself from scratch how to master the games of chess,** [**shogi**](https://en.wikipedia.org/wiki/Shogi)**(Japanese chess), and** [**Go**](https://en.wikipedia.org/wiki/Go_(game))**, beating a world-champion program in each case.**


AlphaZero uses [[Monte Carlo Tree Search (MCTS)]] to simulate and evaluate game. Then it trains policy and value network. Policy uses [[Activation Functions#Cross Entropy Loss]], value network uses MSELoss.
