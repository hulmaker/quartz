# Attributes of system

It is vital to understand philosophy behind the application(s) represented by several attributes (rules). To understand used terms, please visit [[Vocabulary]].

_For time being described in iC Cloud terms._

## Customer

* A customer can have one or multiple properties.

## Property

* Property can have one or multiple sensors.

## Sensor

* A sensor can cover multiple entrances.

## Entrance Group
* An entrance group consists of one or multiple entrances.

## User
* An user can be assigned to ONLY ONE customer.
* An user can have ONLY ONE role.
* An user can be assigned to multiple properties within ONE customer.
* An user can be assigned to multiple entrance groups within assigned properties.
* An user can be granted access to multiple pages via role system.
