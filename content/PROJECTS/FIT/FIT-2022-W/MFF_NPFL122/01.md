## $\varepsilon$-greedy method - iteration algorithm
* Action $A_t$ 
* Reward $R_t$
* Expected reward over all actions $Q_t$ - OPTIMIZATION OBJECTIVE
* algorithm: 
	* $P(\text{greedy action}) = 1-\varepsilon$
	* $P(\text{random action}) = \varepsilon$
	* estimate $Q_{n+1}$ (with update)


## Markov Decision Process
Pobability process with complete states. Each transition provides a reward. Each action leads from state $s$ to state $s^`$ with some probability. Rewards in future are discounted, we care mainly for rewards in the near future. Return is a sum of all rewards weighted by discount factor.


## Monte Carlo Methods
Based on empiric observations. First we sample the space to learn a model. Then we use the best action in each decision. (greedy)
