**Title: Dataset for Hazmat Placard Classification — Development Plan**
**1. Data Extraction Pipeline**
- Parse video metadata.
- Detect box ROI in each frame.
- Identify overlapping frames for each ROI.
- Map ROI coordinates to each overlapped frame.
- Crop ROI from frames.

**2. Data Quality Rules**
- Skip cropping if ROI touches frame edge (within 25% width).
- Limit per-ROI output to max 3 frames; if fewer available, pick 1.
- Ensure consistent naming and indexing.

**3. Long-Tail Distribution Handling**
- Harvest all metadata first.
- Build a large metadata table:
	- data for downloading the frame - name, path, panopath, detection event path...
	- context - sighting, car position
	- geometry - intersection, roi, image size
	- class, quality flags.
- Analyze frequency per class.
- Define sampling strategy for rare vs frequent classes.

**4. Two-Pass Architecture**
- **Pass 1: Metadata Only**
    - Load all metadata from videos.
    - Apply quality rules (edge detection, frame limiting).
    - Store only text/metadata (no images).
    - Produce a single structured table (CSV or parquet).
- **Pass 2: Selected Subset Download**
    - Sample from metadata table according to class-balance strategy.
    - Download only needed frames.
    - Perform ROI cropping.
    - Save final cropped images + labels.

**5. Implementation Steps**
- Create metadata loader module.
- Implement ROI quality filter.
- Implement frame overlap resolver.
- Build metadata table generator.
- Implement sampler for long-tail balancing.
- Build image downloader + ROI cropper.
- Add logging and progress tracking.
- Add unit tests for ROI filters, overlap logic, and frame selection.

**6. Outputs**
- Metadata table (full).
- Final balanced dataset (images + labels).
- Summary report: counts per class, discarded ROI stats.
