# Cloud
* rozdělit db na pracovní a cloudovou, která bude obsahovat zpracovaná data vhodná pro vizualisace
* najímat člověka tak, aby se rovnou pustil do implementace toho
* Nemám moc dobré povědomí o těch technologiích, ušetřilo by čas toho člověka kontaktovat
* Info o platu, Franta?

1. **Tableau:**
    - Description: Tableau is a popular and widely-used data visualization platform that allows users to create interactive and shareable dashboards. It supports a variety of data sources and provides a user-friendly interface for designing visualizations.
    - Website: [Tableau](https://www.tableau.com/)
2. **Grafana:**
    - Description: Grafana is an open-source platform for monitoring and observability. It supports various data sources, including time-series databases, and provides customizable dashboards with the ability to create dynamic and interactive visualizations.
    - Website: [Grafana](https://grafana.com/)
3. **Power BI:**
    - Description: Microsoft Power BI is a business analytics service that enables users to create interactive dashboards and reports. It integrates seamlessly with Microsoft's ecosystem and supports a wide range of data connectors.
    - Website: [Power BI](https://powerbi.microsoft.com/)
4. **Looker:**
    - Description: Looker is a modern data platform that allows users to create and share interactive dashboards. It provides a modeling layer for data exploration and integrates with various databases and data sources.
    - Website: [Looker](https://looker.com/)
5. **Dash (Plotly):**
    - Description: Dash is a Python framework for building analytical web applications. It is built on top of Plotly for creating interactive visualizations and enables the creation of custom dashboards using Python.
    - Website: Dash
6. **Metabase:**
    - Description: Metabase is an open-source business intelligence tool that simplifies the process of creating dashboards and asking questions about your data. It supports various databases and provides a user-friendly interface.
    - Website: [Metabase](https://www.metabase.com/)
7. **Kibana:**
    - Description: Kibana is an open-source data visualization platform designed for Elasticsearch. It is commonly used for log and time-series data analysis, offering powerful visualization and exploration features.
    - Website: Kibana
8. **Redash:**
    - Description: Redash is an open-source data visualization and dashboarding platform that connects to various data sources. It provides a simple and intuitive interface for creating and sharing visualizations.
    - Website: [Redash](https://redash.io/)
9. **Sisense:**
    - Description: Sisense is a business intelligence platform that allows users to create interactive dashboards and reports. It supports data integration from various sources and provides a drag-and-drop interface for visualization creation.
    - Website: [Sisense](https://www.sisense.com/)
10. **Periscope Data:**
    - Description: Periscope Data is a data analysis platform that provides tools for creating interactive dashboards, charts, and reports. It allows for SQL-based querying and supports collaboration within teams.
    - Website: [Periscope Data](https://www.sisense.com/)
